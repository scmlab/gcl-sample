# gcl-sample

GCL examples for local Visual Studio Code.

1. Install [Visual Studio Code](https://code.visualstudio.com/).
2. Clone or download this repository, then open its folder in VS Code.
3. Install or update **gcl-vscode** by **scmlab** to the latest stable version from the [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=scmlab.gcl-vscode). You can also find it under the workspace's recommended extensions.
4. Open `swap.gcl` or `fastmul.gcl`. After editing, press `Ctrl+C`, then `Ctrl+L` to run **GCL: Reload** and update the verification results.

The extension includes the GCL language server and Z3 for supported platforms.

For Codespaces or a local Dev Container, see https://github.com/scmlab/gcl-sample-container .
